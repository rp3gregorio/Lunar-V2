# Phase 0 — Quickstart

Smoke-test the `lunar` package on a fresh clone.

| Notebook | What it does |
|---|---|
| `00_quickstart.ipynb` | Imports every public module (grid, properties, solver, illumination, validation), runs an analytical-wave regression test, and prints the versions of every dependency. |

Run this first. If it completes without errors, the environment is
ready for Phase 1.
